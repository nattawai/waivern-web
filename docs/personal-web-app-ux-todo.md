## 4. เรื่องที่ต้องจำตอนเขียนโค้ด (เฟส 3–7)

1. 🔴 **ข้อความธรรมดาหลายบรรทัดจะยุบเป็นบรรทัดเดียวบน HTML** — ต้องใส่ `white-space: pre-wrap` (Tailwind: `whitespace-pre-wrap`) ที่จุดแสดงผล ไม่งั้นการขึ้นบรรทัดที่ผู้ใช้พิมพ์จะหายหมด
2. เก็บข้อมูล**ดิบ**เสมอ อย่าแปลงก่อนเก็บ — ข้อมูลดิบเปลี่ยนรูปแบบทีหลังได้ แต่ของที่แปลงแล้วย้อนกลับยาก
3. การเลือกเก็บเป็น plain text วันนี้ **ไม่ปิดประตูอะไร** — ถ้า v2 อยากไป Markdown หรือ TipTap ก็อ่านข้อความเดิมเข้าไปได้
4. เมื่อถึง v2 ที่เก็บ HTML จาก rich editor **ต้องกรอง XSS ทุกจุดที่แสดงผล** เพราะเว็บนี้มีสมาชิกหลายคน
5. หน้า To-do เป็นหน้าที่เขียนข้อมูลมากที่สุด → **row-level authorization ต้องครอบทุก endpoint** และต้องมี test พิสูจน์ว่า user A แตะของ user B ไม่ได้
